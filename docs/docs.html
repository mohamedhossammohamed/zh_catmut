Overview

zh_catmut is a native Python package for remapping Pandas categorical code buffers through a strict C ABI. It is designed for large categorical columns where the labels are tiny metadata but the code buffer contains millions or hundreds of millions of integer rows.

The core idea is to keep semantic work in Python and move repetitive full-column work to native code. Python builds the target category list and an int64 lookup table. The native Zig library receives borrowed pointers and primitive fields, validates the planned remap, then mutates or copies the integer codes in one batch.

Best fit

Relabeling, merging, or aligning categorical labels without expanding a full column into Python objects.

Not the goal

Passing strings, dicts, Pandas objects, JSON, or object arrays into native code.

Safety posture

Validate before mutation, reject ambiguous ownership, and preserve Python-owned buffers.

Native primitive

A dense LUT remap over signed integer code buffers with missing-code preservation.

Installation

Install the package from Python packaging infrastructure with pip: 

pip install zh-catmut

Runtime dependencies are NumPy and Pandas. The package is intended to bundle a platform shared library inside the Python package directory: libzh_catmut.so on Linux, libzh_catmut.dylib on macOS, and zh_catmut.dll on Windows.

Prebuilt wheel expectation

End users should not need a native compiler when installing a wheel that already includes the shared library.

Quickstart

Use the high-level API when working with Pandas objects. The return type mirrors the input: a Series returns a Series with the same index and name, while a Categorical returns a Categorical. 

import pandas as pd
from zh_catmut import remap_categorical

s = pd.Series(
    pd.Categorical(["new", "old", "old", None]),
    name="status",
)

out = remap_categorical(
    s,
    {"old": "new"},
    copy_fallback=True,
)

print(out.tolist())

copy_fallback=True is the practical default for callers who want safety without reasoning about Pandas Copy-on-Write ownership. It allocates a Python-owned destination codes buffer and leaves the original source buffer unchanged.

Mental model

Pandas categoricals are dictionary encoded. The category labels are stored once, while the full column is stored as a dense integer array. Missing values use the sentinel code -1.

categories 0 → "pending"
1 → "active"
2 → "old"
codes [0, 2, 1, -1]
dtype=int8
contiguous
lut [0, 1, 1]
new_code = lut[old_code]

If "old" maps to "active", Python builds a target category list and a lookup table where the old code for "old" points at the target code for "active". Native code never needs to understand the label values.

1
Label mapping Python applies the mapping to old categories and deduplicates target categories in first-seen order.
2
LUT construction Each old category index receives one int64 target category index.
3
Pointer export After gates pass, Python exports code-buffer and LUT pointers through ctypes.
4
Native remap Zig validates every code and mapped output before executing mutation or copy.

High-level API: remap_categorical

def remap_categorical(
    obj: pd.Series | pd.Categorical,
    mapping: Mapping[object, object],
    *,
    assume_unique: bool = False,
    copy_fallback: bool = False,
    threads: int = 0,
) -> pd.Series | pd.Categorical:
    ...

This is the ergonomic API for category label remapping. Categories not present in mapping are preserved. Multiple source labels may map to the same target label, and target categories preserve first-seen order after deduplication.

Parameter Meaning
obj A Pandas Series with categorical dtype or a pd.Categorical.
mapping A mapping from old labels to new labels. Missing mapping keys keep their original labels.
assume_unique Opt-in escape hatch for controlled in-place mutation after all other gates pass.
copy_fallback Allocates a destination buffer and uses the native copy path when in-place ownership is not desired.
threads Forwarded to the native call. The current scalar implementation accepts the parameter.

Return behavior

  • Series input returns a Series preserving index and name.
  • Categorical input returns a new Categorical.
  • Missing values stay missing.
  • Ordered categoricals preserve the original ordered flag.
In-place mode is intentionally strict

Without copy_fallback=True or assume_unique=True, high-level mutation is rejected when unique ownership cannot be proven.

Low-level API: remap_codes_inplace

def remap_codes_inplace(
    codes: np.ndarray,
    lut: np.ndarray,
    *,
    target_category_count: int,
    missing_code: int = -1,
    allow_missing: bool = True,
    threads: int = 0,
) -> NativeExecutionReport:
    ...

Use this only when you already own the codes array and have already built a correct dense int64 lookup table. This API mutates codes in place after Python and native validation succeed.

Input Requirement
codes One-dimensional, C-contiguous NumPy array with dtype int8, int16, int32, or int64.
lut One-dimensional, C-contiguous NumPy array with dtype int64.
target_category_count Every mapped non-missing code must be in [0, target_category_count).
missing_code Missing sentinel, defaulting to -1 to match Pandas categorical codes.
allow_missing When false, missing input codes or missing LUT outputs are rejected before mutation. 
import numpy as np
from zh_catmut import remap_codes_inplace

codes = np.array([0, 1, 2, -1], dtype=np.int16)
lut = np.array([0, 0, 1], dtype=np.int64)

report = remap_codes_inplace(
    codes,
    lut,
    target_category_count=2,
)

assert codes.tolist() == [0, 0, 1, -1]
assert report.item_count == 4

Native calls return plain report structs that are wrapped as frozen Python dataclasses. These reports make validation and execution observable without exposing native memory ownership to Python.

Safety gates

zh_catmut treats native mutation as a privileged final step. Python-side gates run before pointer export, and native validation runs before a mutation path writes anything.

Dtype gate

Codes must be signed integer categorical code dtypes: int8, int16, int32, or int64.

Shape gate

Codes and LUT arrays must be one-dimensional and C-contiguous.

Bounds gate

Lengths, target category counts, missing codes, and thread counts are checked before native calls.

Writeability gate

NumPy writeability is temporarily managed for the native call and restored afterward.

CoW gate

High-level in-place mutation is rejected when Pandas storage sharing cannot be ruled out.

Native gate

The Zig predictor validates source and target ranges before mutation.

All-or-nothing mutation

If native validation detects an invalid source code, invalid mapped code, null pointer, unsupported dtype, or oversized length, the in-place mutation path fails before writing elements.

Native ABI

The native library exposes stable C symbols and is loaded through ctypes.CDLL. The loader declares exact argument and return types, then verifies that the native ABI version matches the Python wrapper expectation. 

zhcm_abi_version
zhcm_status_message
zhcm_predict_remap_lut
zhcm_remap_lut_inplace
zhcm_remap_lut_copy

Native functions receive only primitive data:

  • void * or const void * pointers for code buffers.
  • int64_t * pointer for the dense LUT.
  • uintptr_t lengths.
  • Integer dtype IDs.
  • Primitive flags.
  • Caller-allocated report structs.

Native code never stores borrowed pointers after return, frees Python-owned buffers, calls the Python C API, accepts Python objects, or writes outside the logical element count.

Memory ownership

V1 is Python-owned-buffer-only. The native library does not allocate output buffers. In copy fallback mode, Python allocates np.empty_like(codes) and passes both source and destination pointers to native code.

A
In-place path Mutates codes[0:item_count] only after safety and native prediction gates succeed.
B
Copy path Reads source codes and writes a Python-owned destination buffer, preserving the input.
C
Cleanup Python keeps arrays alive for the duration of ctypes calls and restores temporary writeability in a final boundary.

Errors

Errors are grouped by where the failure occurs. Python-side gate failures use Python exceptions directly. Native status failures are converted into NativeStatusError with the native message and report attached.

Exception When it appears
ZhCatmutError Base exception for package-specific failures.
NativeLibraryLoadError The bundled native library cannot be loaded or the ABI version mismatches.
NativeStatusError A native function returns a non-zero status.
MemoryGateError Python rejects shape, dtype, contiguity, bounds, or other memory invariants.
CopyOnWriteSafetyError High-level in-place mutation cannot be proven safe under Pandas Copy-on-Write checks.

Packaging and distribution

The package metadata uses setuptools as the build backend. The build process invokes Zig to compile the shared library, then copies the resulting platform library into the Python package directory so it can be loaded through importlib.resources.

Python package

Source lives under src/zh_catmut and exports remap_categorical plus remap_codes_inplace.

Native source

Zig build configuration lives under native/build.zig with native implementation under native/src/root.zig.

C header

The ABI contract is represented by include/zh_catmut_abi.h.

Package data

Shared library names are included as package data for Linux, macOS, and Windows.

Usage patterns

Safe production remap

Prefer copy_fallback=True when the source Series might share storage or when preserving the original input is important. 

out = remap_categorical(
    df["status"],
    {"pending": "active", "legacy_disabled": "disabled"},
    copy_fallback=True,
)

Controlled in-place remap

Use assume_unique=True only when you control the data lifecycle and know the categorical codes buffer is uniquely owned. 

out = remap_categorical(
    series,
    {"old": "new"},
    assume_unique=True,
)

Low-level buffer remap

Use the low-level API for integration code that already owns the NumPy buffer and can construct a dense LUT without Pandas labels. 

report = remap_codes_inplace(
    codes,
    lut,
    target_category_count=len(target_categories),
    allow_missing=True,
)

Troubleshooting

I get CopyOnWriteSafetyError.

Use copy_fallback=True unless you can prove that the categorical codes buffer is uniquely owned. This is the expected safe path for shared Pandas storage.

I get unsupported codes dtype.

The low-level codes array must be a NumPy ndarray with dtype int8, int16, int32, or int64. Object arrays and unsigned integer arrays are rejected.

I get a contiguity or shape error.

The codes and LUT arrays must be one-dimensional and C-contiguous. Convert or copy non-contiguous arrays before calling the low-level API.

I get NativeLibraryLoadError.

The bundled shared library is missing, cannot be loaded by the platform dynamic loader, or reports an unexpected ABI version. Reinstall the package or rebuild the native library for the current platform.

Should I pass threads?

The API accepts a thread request for ABI stability and future native kernels. The current implementation uses the scalar native remap path.
