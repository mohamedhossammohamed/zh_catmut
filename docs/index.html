Remap categorical columns at native speed.

zh_catmut targets the dense integer payload inside Pandas categoricals. It keeps labels and category reconciliation in Python, then sends raw contiguous code buffers through a narrow ABI to a bundled Zig remapping core.

The bottleneck

Huge categoricals are compact until remapping gets expensive.

A Pandas categorical stores a small category dictionary plus one dense signed integer code per row. High-level relabeling and alignment can allocate replacement arrays, masks, or object-mode intermediates. zh_catmut goes straight to the integer buffer.

High-level remapping path

Convenient APIs can perform full-column re-encoding work or allocate temporary buffers that dominate runtime and memory pressure on very large columns.

series = series.cat.rename_categories({
    "pending": "active",
})
series = series.cat.set_categories([
    "active",
    "disabled",
])

zh_catmut remapping path

Build the mapping once from metadata, validate every invariant, then mutate or copy the dense integer codes in one native batch.

from zh_catmut import remap_categorical

series = remap_categorical(
    series,
    {"pending": "active"},
    copy_fallback=True,
)
Design language

A safety gate wrapped around a very small native primitive.

The project has a systems vibe: dark data planes, ABI seams, zero-copy intent, and a hot loop that only knows integers. The website mirrors that with glass panels, signal colors, and moving code-buffer traces.

Categorical metadata

Python reads the old categories and mapping, then creates target categories in first-seen order.

Dense LUT

Each source category index maps to a new category index through one contiguous int64 array.

Memory gates

Shape, dtype, contiguity, integer bounds, writeability, and CoW safety are checked before pointers leave Python.

Native validation

Zig predicts the remap and rejects invalid source codes, invalid outputs, and missing-policy violations before mutation.

Batch remap

The native core executes the LUT loop and returns a POD execution report with counts and status fields.

What makes it fast

Move the full-column work to native code. Keep the meaning in Python.

The API is intentionally narrow. Category labels, dictionaries, Pandas objects, strings, JSON, and object arrays do not enter native code. The native core only receives borrowed primitive memory.

LUT

Dense lookup table

Category remapping becomes the simple operation new_code = lut[old_code].

Zig

Native loop

A bundled shared library handles int8, int16, int32, and int64 code buffers.

ABI

Strict C boundary

Only pointers, lengths, dtype IDs, flags, and report structs cross the boundary.

CoW

Pandas-safe return

The result is reattached through pd.Categorical.from_codes(..., validate=False) after validation.

QuickstartPandas
import pandas as pd
from zh_catmut import remap_categorical

s = pd.Series(pd.Categorical([
    "new",
    "old",
    "old",
    None,
]))

out = remap_categorical(
    s,
    {"old": "new"},
    copy_fallback=True,
)
Public API

Two entry points: one high-level, one low-level.

Use remap_categorical when you have Pandas objects. Use remap_codes_inplace only when you own a writable, contiguous NumPy codes buffer and a dense int64 LUT.

remap_categorical(obj, mapping, *, assume_unique=False, copy_fallback=False, threads=0) High-level category-label remapping for pd.Series with categorical dtype or pd.Categorical.
remap_codes_inplace(codes, lut, *, target_category_count, missing_code=-1, allow_missing=True, threads=0) Low-level native remap for a contiguous signed integer NumPy codes buffer.
NativeExecutionReport Frozen dataclass containing ABI version, status, flags, item counts, changed counts, missing counts, and first-invalid diagnostics.

Minimal low-level call

import numpy as np
from zh_catmut import remap_codes_inplace

codes = np.array([0, 1, 1, -1], dtype=np.int8)
lut = np.array([0, 0], dtype=np.int64)

report = remap_codes_inplace(
    codes,
    lut,
    target_category_count=1,
)

assert codes.tolist() == [0, 0, 0, -1]
